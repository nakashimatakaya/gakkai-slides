# 構成規則の詳細

## 標準の並び

タイトル → COI → 背景・目的 → 方法 → 結果・考察 → 結論 →（謝辞）→ 予備スライド

- タイトル: 演題名、演者（共同演者含む）、所属、学会名、日付（ガレメン）。
- COI: 医学系学会では口演スライドの2枚目に開示する。日本麻酔科学会は支部学術集会を含む学術集会で、口演はスライド2枚目、ポスターはパネル下部への開示を義務付けている。日本医学会のCOI管理ガイドラインは「最初か2番目のスライド」。文言と様式は学会指定があれば必ずそれを使う。開示例:「本演題に関連し、開示すべきCOI関係にある企業等はありません」。
- 背景・目的: 疾患負担・臨床疑問を数枚で。目的は1文で言い切る。
- 方法: デザイン、対象、曝露・アウトカムの定義、解析。再現の粒度ではなく、結果を読むのに必要な粒度。
- 結果・考察: 発表では同時に展開する。聴衆は論文と違って図表を後から見返せない（ガレメン）。
- 結論: 主要な数値と含意を1〜2枚。「さらなる検討が望まれる」だけで終えず、次に何をどう見るかを書く。
- 謝辞: 入れるなら1枚に一文＋所属名程度（ドキュメントプラス）。
- 予備スライド: 想定質問3つ分。感度分析、サブグループ、除外の内訳、先行研究との対比表が定番。

## 枚数と時間

- 本文1分1枚が目安（ガレメン）。タイトル・COIなど内容の薄い枚数は数えない。±2〜3枚は許容。
- それ以上ズレるなら、1枚の情報量か話す速度がおかしい。
- 10分発表の時間配分の目安: 背景・目的2分、方法2分、結果・考察5分、結論1分（ドキュメントプラス）。
- 1枚に3分かけるスライドは分割する。逆に、複雑な図は理解の時間を取る（切り替えが早すぎると聴衆が置いていかれる）。
- 目次は20分超の発表だけ。10〜15分では入れない（ガレメン）。

## スライド1枚の中身

- 1スライド1メッセージ。そのスライドで何を主張したいかを下部に1行で書く（ガレメン）。
- 研究発表では図が複数枚になってよい。タイトル＋複数の図表＋各説明＋まとめ1つの構成も普通。
- 話すことは書く、話さないことは書かない。触れないことは「時間の関係で省略します」と言うか予備に回す（ガレメン）。
- 参考文献は引用したスライドの下部に番号付きで書く。最後にまとめて出しても、聴衆はどれがどこの引用か覚えていない（ガレメン）。目立ちすぎず、確実に読めるサイズ（12〜14pt）。
- 引用図表は出典明記。改変したら「〜より改変」。他人のデータの転載は許可を取る（ドキュメントプラス）。
- 患者情報は同意と匿名化を確認する。倫理審査を通った研究でも発表用に改めて加工する（ドキュメントプラス）。

## 提出・当日

- 提出形式（PPTX/PDF/比率/ファイル名/期限）を学会案内で確認する。
- フォント埋め込みかPDF化で崩れを防ぐ。国際学会では日本語フォントが出ないことがあるので英語スライドは欧文フォントのみ。
- USBとクラウドに二重保存。接続端子と発表PCのOSを確認。
- 練習はタイマーで通しで行い、録画して言い淀みと指示語の多さを確認する（ドキュメントプラス）。
- カンペなしで話せるスライド（要点と主張が書いてある）を作るのが結局いちばんの対策（ガレメン）。対面では実物のレーザーポインタを推奨。
